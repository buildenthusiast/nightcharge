# Други марки: официални източници

Проверено: 2026-10-15. Не е намерена пълна документация за никоя марка извън Deye. Прокси сесията блокира или връща празни страници за повечето официални портали.

## Solis (SolisCloud)

- Източник: официална поддръжка на Solis, „SolisCloud API Guide“: https://usservice.solisinverters.com/support/solutions/articles/73000591225-soliscloud-api-guide
- Ключове: заявка до usservice@solisinverters.com с имейла на акаунта или Organization Code. След одобрение: SolisCloud в браузър → Service → API Management → „Activate now“ → „View Key“. Кодът се праща по имейл (6 цифри). Може само от компютър.
- Получаваш: **KeyID**, **KeySecret**, **API URL**.
- Ограничение: статията е само за клиенти в САЩ и Канада.
- Не е проверено: схемата на подписа, базовият URL, endpoint-ите за станции и аварии. Те са в PDF „SolisCloud Platform API Document V2.0.3“, който не е прочетен (линкът е в статията).

## Victron (VRM)

- Опит: https://vrmapi.victronenergy.com/ върна грешка при четене.
- Не е проверено. Търсенето даде само форуми на Victron (community.victronenergy.com), не официална документация. Токен се създава в VRM портала (персонален access token). Това е от форумите, не от документация.

## Sungrow (iSolarCloud)

- Опит: https://developer-api.isolarcloud.com/ показа само заглавието „Sungrow Developer Portal“. Съдържанието не е прочетено.
- Не е проверено.
